# 几何框线封面：默认规范与提示词

这是用户指定的**默认封面风格**。为新增项目或文章制作封面时，直接使用本规范；只有用户明确指定其他风格时才切换。

## 固定视觉语言

- 横向 16:9；SVG `viewBox="0 0 1600 900"`；背景满幅，不画外边框。
- `fill="none"`，`stroke-width="6"`，`stroke-linecap="round"`，`stroke-linejoin="round"`。少量实心节点是允许的，不能靠细碎装饰填满画面。
- 一个主要关系，最多三个辅助元素。主体整体居中，占宽度约 55–65%，外侧至少留 12% 空间。
- 首先明确对称轴：垂直轴、水平轴、中心对称，或等宽等距的重复框架。圆角、节点大小、线长和间距按同一组几何数值确定。
- 内容需要差异时允许重复框架内部变化，例如同样大小的清晨、白天、夜晚风景。对称服务于秩序，不要为了镜像而歪曲内容。
- 一张图只用一个浅色背景和一种较深的线色。不要阴影、颗粒、渐变、3D、发光、标题、日期、标签、水印或产品图标。
- 亮、暗主题共用相同封面，不反色，不加 CSS 滤镜。

## 固定色板

| 色组 | 背景 | 线色 |
| --- | --- | --- |
| 蓝 | `#E1E6F4` | `#5267A9` |
| 绿 | `#E1EAE5` | `#567A6D` |
| 紫 | `#EAE5F1` | `#7C689B` |
| 沙 | `#ECE8DF` | `#8A6F54` |
| 桃 | `#EEE5DD` | `#9A7257` |

同一主题系列沿用色组，不能每次随机换色。正式参考图见 `public/covers/agent-safety.svg`、`wallpaper-shift.svg` 和 `xiaobai.svg`。

## 可直接交给 AI 的提示词

```text
为 SandyKid 的网站制作一张“几何框线”封面。

类型：{文章 / 项目}
名称：{真实名称，仅用于理解，不画入图内}
内容摘要：{从文章正文或 README 提炼的两至三句内容}
核心观点或用途：{一句话}
视觉隐喻：{一个明确的几何关系}
对称方式：{垂直轴 / 水平轴 / 中心对称 / 等宽等距框架}
背景色：{指定色板值}
线色：{指定色板值}

输出自包含 SVG，viewBox 为 0 0 1600 900，无外部依赖。
统一 6 单位线宽、圆端点、圆连接；以轮廓为主，最多三个辅助元素。
主体居中，占画面宽度约 55–65%，外侧至少留 12% 留白。
用精确坐标保证框架对称、节点等大、间距一致。
一个背景色、一种线色；无阴影、渐变、纸感、3D、发光。
无标题、文字、图标、Logo、日期、水印和虚构界面。
项目图标由网页单独显示，不得融入封面。
参考本仓库 public/covers/ 内已批准的框线构图和线宽。
不要直接改名复用不相关图形，必须表达本次内容的真实含义。
```

## 交付与检查

1. 写入 `public/covers/{slug}.svg`，包含简短、真实的 `<title>`。
2. 320px 卡片宽度下应能辨认主体；不得靠细小文字说明主题。
3. 数值检查对称轴、等宽框架、圆角和节点间距，避免只凭“看起来差不多”。
4. 文章写入 `cover: {src, alt}`；项目写入 `src/data/projects.ts`。
5. 图标仅放在项目标题旁；没有图标就不显示，不凭空制作新品牌标志。
6. 在亮、暗页面和手机宽度检查后，登记 `design/cover-systems/cover-manifest.json`。

如果用户明确要求位图输出，可将上述视觉规范交给 imagegen，之后仍需检查精确对称与线宽；SVG 是本风格的默认交付格式。
